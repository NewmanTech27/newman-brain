# Tarifa PDBT — Pequeña Demanda en Baja Tensión (CFE)

## Summary
Official CFE tariff page for **PDBT — Pequeña Demanda en Baja Tensión hasta 25 kW-mes**. The
low-voltage entry tariff for business services up to 25 kW, applicable to any use except
services with a specifically fixed tariff. Defines application, the integrated final-rate
structure (Transmisión + Distribución + Operación CENACE + Operación SSB + Servicios Conexos
no-MEM + Energía + Capacidad bundled), monthly minimum, contracted demand, and security
deposit. Adds the bottom rung to the documented CFE commercial tariff ladder
(PDBT → GDBT → [[gdmto]] → [[gdmth]]).

## Key claims
- Applies to **BT services ≤ 25 kW**, any use.
- **Mínimo mensual** = the SSB operation charge.
- **Demanda por contratar** set by the user; fractional kW rounds up.
- **>25 kW → must migrate to GDBT**; auto-reclassified after 3 consecutive months over.
- **Security deposit** by number of current wires: 125 / 350 / 400 kWh for 1 / 2 / 3 hilos (×2 for bimonthly billing).
- Rates set in the CRE "Acuerdos que autorizan o modifican tarifas"; methodology queries → Comisión Nacional de Energía.
